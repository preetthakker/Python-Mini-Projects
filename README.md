Hangman:
**“One of my Python mini-projects is a console-based Hangman game. The main objective of the project was to practice Python fundamentals such as lists, strings, loops, conditional statements, functions of built-in modules, user input, and random selection.

In the game, I maintain a list of programming-related words. The program randomly selects one word, hides its characters using underscores, and asks the user to guess letters. If the guessed letter exists in the selected word, the corresponding position is revealed. If the guess is incorrect, the number of remaining attempts is reduced.

The game continues until either the player successfully guesses the complete word or runs out of attempts.”**

Budget Tracker:
I created a simple command-line Budget Tracker using Python.

The main purpose of the project is to help a user keep track of their budget and expenses.

When the application starts, it asks the user to enter an initial budget. After that, it displays a menu with three options: Add an Expense, Show Budget Details, and Exit.

For adding an expense, the user enters an expense description and its amount. I store the expense description and amount in a dictionary, and I also store the expense amounts in a list so that I can calculate the total expenses easily.

When the user selects Show Budget Details, the application displays the total budget, all the recorded expenses, and the remaining budget. The remaining budget is calculated by subtracting the sum of all expenses from the initial budget.
